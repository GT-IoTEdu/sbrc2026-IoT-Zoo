# IoT-Zoo Architecture

IoT-Zoo is organized around four main layers:

1. Build Layer
2. Orchestration Layer
3. Emulation Layer
4. Data Collection Layer

![Diagrama IoT-Zoo](architecture.png)


## 1. Build Layer

The Build Layer is responsible for preparing Docker images for all infrastructure services and IoT device profiles.

Main file:

- `build_images.sh`

Main directory:

- `devices/`

Each device profile is implemented as an independent Docker image. A typical profile directory contains:

- `Dockerfile`: defines the container environment.
- `client.py`, `urban_sensor.py`, `ip_camera.py`, or equivalent: defines the runtime behavior.
- Dataset files or compressed dataset files, when applicable.

## 2. Orchestration Layer

The Orchestration Layer is implemented in:

- `run_experiment.py`

This script creates the Containernet topology, adds Docker containers as network nodes, assigns IP addresses, connects all nodes to the virtual switch, starts infrastructure services, starts device clients, and captures traffic.

Main responsibilities:

- create the Containernet network;
- add the MQTT broker;
- add IoT device containers;
- add the video server and video clients;
- connect all nodes to switch `s1`;
- add the NAT gateway;
- start services and clients;
- capture packets with `tcpdump`;
- stop and clean the experiment.

## 3. Emulation Layer

The Emulation Layer contains infrastructure services and pluggable device profiles.

Infrastructure services include:

- MQTT broker;
- video server;
- NAT gateway.

Device profiles include:

- smart building;
- air quality;
- industrial monitoring;
- healthcare;
- smart agriculture;
- urban observatory sensors;
- CCTV video profiles.

Each profile reads a dataset or generates application data and converts it into network traffic, usually MQTT or RTSP.

## 4. Data Collection Layer

The Data Collection Layer captures the generated traffic as PCAP files.

The main output is:

- `.pcap` file generated by `tcpdump`.

Optional post-processing is available in:

- `convert_pcap_to_csv/`

This converter transforms PCAP files into enriched CSV datasets for machine learning and network traffic analysis.
